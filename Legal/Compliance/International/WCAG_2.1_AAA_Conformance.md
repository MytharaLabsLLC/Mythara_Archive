**Evaluator:** none — no evaluation has been performed

> **⚠ NOT EVALUATED — NO CONFORMANCE CLAIM**
>
> This document is a **blank evaluation checklist**, kept on file so that a future
> accessibility evaluation has a complete list of criteria to work through. Every
> criterion below is marked **Not Evaluated**. An earlier draft of this document
> marked all 78 criteria as ✅ PASS with detailed implementation claims. Those
> claims were fabricated — no testing was performed — and have been removed.
> Nothing in this document asserts WCAG 2.1 conformance at any level (A, AA, or AAA).

## How to use this checklist

When a real evaluation is performed, each row should be updated with one of:
`Supports`, `Partially Supports`, `Does Not Support`, or `Not Applicable`, plus dated
evidence (test method, tool, tester, build under test). Until then, every row stays
`Not Evaluated`.
