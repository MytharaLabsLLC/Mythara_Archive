## 📖 Terms and Acronyms

**API** — Application Programming Interface. A set of protocols and tools for building software applications and enabling communication between systems.

**Blessings Reservoir (BR)** — A cumulative metric tracking benevolent force, sacred actions, and positive impact over time. Externally framed as "Resonance Reservoir" for enterprise audiences.

**Bearer Token Authentication** — Security method requiring `Authorization: Bearer {api_key}` header for API access.

**Biblical Continuum** — Range from Wilderness/Darkness (trial/testing) to Grace/Light (peak alignment/divine favor). Intermediate states include River (covenant flow) and Promise (sacred assurance).

**Breach Response Mode** — Automated quarantine and logging activated when suspicious activity detected.

**Challenge State** — Industry-safe term for Wilderness/Darkness (biblical continuum anchor for trial conditions).

**Challenge Vector** — Industry-safe term for Trial Entity (models decision friction factors).

**Clause** — A symbolic unit of action or rule within Mythara Engine. Types include: Provisioning, Grief Capsule, Sanctification Lock, Resurrection, Chameleon, ELE Capsule.

**Clause Invocation** — The act of executing a clause with specific payload, messenger, and consent token.

**Commandments (C)** — Sacred obligations or compliance requirements that guide decision-making.

**Communication Alignment** — Industry-safe term for Messenger Pairing Fidelity (measures alignment between actions and communication).

**Compliance Stability** — Industry-safe term for Divine Drift Suppression (measures drift from sacred mission).

**Consent Token** — Required parameter for clause invocation ensuring user authorization.

**Continuity Index** — Industry-safe term for Legacy Reservoir (reflects sustainability and cultural resonance).

**Cradle Integrity (I)** — Calculated as: `I = Alignment(C) × Tolerance(W)`. Measures obedience under paradox.

**CRM** — Customer Relationship Management. Software system that manages company interactions with customers and prospects.

**Divine Drift Suppression** — Measures drift from sacred mission or core values. Externally framed as "Compliance Stability."

**Dual-Framing Translation Layer** — Presentation layer converting mythic terminology to enterprise-safe language without changing underlying engine logic.

**ELE Capsule Mode** — Emergency lockdown mode activated during security incidents.

**Emotional Fidelity** — Measures symbolic-emotional resonance accuracy. Externally framed as "Sentiment Accuracy."

**Engagement Index** — Industry-safe term for Expression Metric (captures how individuals connect and resonate with others).

**Escrow-Ready** — Code and documentation prepared for third-party escrow deposit with verification instructions.

**Expression Metric** — Captures how individuals present, connect, and resonate with others beyond raw numbers. Externally framed as "Engagement Index."

**Framing Mode** — API parameter controlling terminology used in responses. Options: `mythic` (default) or `industry`.

**GDPR** — General Data Protection Regulation. European Union data protection and privacy law.

**Grace/Light** — Biblical continuum anchor representing peak alignment, divine favor, and positive outcomes. Externally framed as "Optimal Performance."

**HIPAA** — Health Insurance Portability and Accountability Act. U.S. federal law protecting sensitive patient health information.

**Impact Vault** — Industry-safe term for Soul Encoding (stores symbolic depth of actions).

**Integrity Hash** — SHA-256 cryptographic hash computed for audit trail verification. Always computed on mythic terms regardless of framing mode.

**Integrity Metric** — Measures alignment with compliance, honesty, and reliability in field performance. Externally framed as "Trust Index."

**KPI** — Key Performance Indicator. Measurable value demonstrating how effectively a company achieves key business objectives.

**Legacy Reservoir** — Reflects sustainability and cultural resonance over time. Externally framed as "Continuity Index."

**Manager Dashboard** — Visual interface displaying KPIs from System of Record alongside Mythara's resonance metrics. Supports toggle between mythic and industry framing.

**Messenger** — Entity responsible for transmitting, recording, or executing symbolic actions. Roles include: Scribe (recording), Healer (restoration), Watcher (observation), Herald (announcement), Avenger (justice), Custodian (preservation), Witness (testimony).

**Messenger Pairing Fidelity** — Measures alignment between actions and communication. Externally framed as "Communication Alignment."

**Optimal Performance** — Industry-safe term for Grace/Light (biblical continuum anchor for peak alignment).

**Overlay Layer** — Mythara's integration approach—adding symbolic depth on top of existing systems without disrupting workflows or compliance.

**PHI** — Protected Health Information. Any health information that can identify an individual (protected under HIPAA).

**Pilot Deployment** — Limited-scope implementation for testing and validation before full enterprise rollout.

**Promise** — Intermediate state on biblical continuum representing sacred assurance and commitment to outcomes.

**Rate Limiting** — Throttling mechanism preventing excessive API requests (default: 100 requests per 60 seconds).

**RBAC** — Role-Based Access Control. Permission system assigning different capabilities based on API key roles (read, invoke, admin, audit).

**Resonance Metrics** — Industry-safe term for Mythara's symbolic measurements (Blessings Reservoir, Integrity Metric, Expression Metric, etc.).

**Resonance Operator** — Industry-safe term for Soul Cradle Operator (measures decision-making integrity under pressure).

**Resonance Reservoir** — Industry-safe term for Blessings Reservoir (tracks cumulative positive impact).

**River** — Intermediate state on biblical continuum representing covenant flow and steady progress.

**Sentiment Accuracy** — Industry-safe term for Emotional Fidelity (measures symbolic-emotional resonance).

**SHA-256** — Secure Hash Algorithm 256-bit. Cryptographic hash function used for data integrity verification.

**SOC 2** — Service Organization Control 2. Auditing standard for service providers storing customer data in the cloud.

**Soul Cradle Operator** — Measures obedience under paradox—decision-making integrity when faced with conflicting sacred obligations. Externally framed as "Resonance Operator."

**Soul Encoding** — The process of storing symbolic depth of actions and emotional resonance. Externally framed as "Impact Vault."

**Soul Proportion Model** — A bounded [0,1] metric representing emotional vitality and coherence. NOT additive across people, NOT directly comparable without calibration. Used as a reflective/supportive indicator, never as a gatekeeper.

**Sovereign Deployment** — Air-gapped installation for governments or organizations requiring complete data isolation.

**SSIP** — Symbolic Safety Integrity Protocol. Mythara's proprietary framework ensuring emotional fidelity and compliance.

**System of Record** — Primary system storing authoritative data (e.g., CRM, field platform, ERP). Mythara overlays onto this system without replacing it.

**Trial Entity (T)** — Models testing, obscuration, and challenges in decision-making. Replaces deprecated "Lucifer" terminology. Externally framed as "Challenge Vector."

**Trust Index** — Industry-safe term for Integrity Metric (measures compliance alignment and reliability).

**Wilderness/Darkness** — Biblical continuum anchor representing trial, testing, or suboptimal conditions. Externally framed as "Challenge State."

**Will (W)** — Tolerance for paradox—the ability to hold conflicting truths simultaneously.
