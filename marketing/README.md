# Mythara Marketing Engine

Every bot works to sell Mythara. This directory is the machine.

## What's here

- `MESSAGE_HOUSE.md` — the single source of truth. Positioning, narrative, proof points, voice, and the forbidden-claims list. Read this before writing anything.
- `ads/` — ad creative sets. Headline / body / CTA, ready to run.
- `seo/` — long-form articles. Useful first, keyword-smart second.
- `social/` — the post queue. Remarkable, quotable, honest.

## The rules (non-negotiable)

1. **Nothing here is published, posted, or sent.** These are drafts. Herb approves every word before anything goes out. The signature grant covers email outreach only — not social, not ads.
2. **Never fabricate.** No customers, no metrics, no certifications, no ROI numbers, no fake urgency, no fake scarcity. The honesty IS the product. An ad that lies is a bug.
3. **No new paid APIs.** Organic only until Herb says otherwise.
4. **Voice: human, direct, sharp.** If it reads like mail-merge, delete it.

## How the machine runs

1. Pick the audience (agent builders, burned developers, the curious).
2. Pick the angle from the message house.
3. Draft from `ads/`, `seo/`, or `social/`.
4. Herb reviews. Herb approves. Then — and only then — it ships.
