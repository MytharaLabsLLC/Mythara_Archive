# Mythara Product Glyph Catalog

This catalog provides ready-to-use, mono-line SVG glyphs for Mythara commercial items. All icons are vector, scalable, and color-inherit via `currentColor`.

---

## Usage

- Inline in HTML/Markdown:
  ```html
  <img src="./assets/glyphs/ssip_audit.svg" width="64" height="64" style="color:#111" />
  ```
- In CSS, set `color` on parent to tint the glyphs.
- All SVGs use: `stroke="currentColor"`, `fill="none"`, `stroke-width="12"`, rounded caps/joins.
