# Archive — retired files

> **Policy (2026-09-27):** Files land here when they are dead weight — deprecated
> duplicates, superseded drafts, stale one-off scripts, or fragments nothing
> references — but deleting them outright would erase history. Each file keeps
> its original relative path under `archive/` (e.g.
> `Commercial/old_draft.md` → `archive/Commercial/old_draft.md`).
>
> What is NEVER archived: tests, active code, legal drafts, forensic and
> historical remediation records, or anything referenced by active code or docs.
> If you need a file back, move it to its original path — nothing here is
> load-bearing.
